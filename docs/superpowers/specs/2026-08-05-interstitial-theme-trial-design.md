# Interstitial между уровнями + «тема на сутки» за rewarded

Дата: 2026-08-05. Источник требований — сообщения V. Mikhailov (монетизация SYNAPSE).

## 1. Interstitial между уровнями

### Конфиг (всё в одном месте, `lib/core/interstitial_gate.dart`)

| Параметр | Значение |
|---|---|
| everyNLevels | 3 |
| minSecondsBetweenAds | 120 (обновлено финальной спекой 05.08: было 300) |
| firstAfterLevel | 10 |
| skipIfRewardedWithin | 60 |
| maxPerSession | 5 |
| onlyAfterWin | true |

Дополнение 05.08 (вторая итерация спеки): боевые id AdMob (app id в
манифестах, 7 блоков по плейсментам — enum `AdSlot`), `useTestAds =
kDebugMode`, предзагрузка rewarded по слотам с TTL 1 час, лимит
подсказок за ролик 6/день (`adh`), `adCont` без числа ходов ×9 языков,
SKAdNetworkItems (50 записей) в Info.plist.

### Поведение

- Слот показа: закрытие ResultOverlay кнопкой «Дальше» после **победы**, до `_startLevel`. После перегрузки и при выходе в хаб — никогда.
- Счётчик побед и таймер работают связкой: показ, когда выполнены **оба** условия (каждая 3-я победа И ≥300 с с прошлого interstitial). Пока таймер не вышел — счётчик не сбрасывается, показ ждёт следующую победу.
- Уровни < firstInterstitialAfterLevel — показов нет (закрывает и «первую сессию»: уровень абсолютный, из сейва).
- Если в последние 60 с был показан ЛЮБОЙ rewarded (x2, продолжение, подсказка, магазин) — слот **пропускается целиком** (счётчик побед сбрасывается), а не откладывается.
- Кап 5 показов за сессию (сессия = запуск процесса, состояние в памяти).
- Ролик предзагружается, когда открыт победный ResultOverlay и статические условия гейта уже выполнены. Если к моменту слота ролик не загружен — слот пропускается без ожидания (счётчик сохраняется), переход на уровень не рвётся.

### Архитектура

- `Ads`: + interstitial (тестовые id Google, `_realInterUnit` — пустые заглушки под релиз), `preloadInterstitial()`, `showInterstitial()` (падает закрыто), `lastRewardedAt` — метка окончания любого rewarded.
- `InterstitialGate` — чистая логика с инъекцией часов (тестируемая): `recordWin()`, `readyToPreload(level)`, `shouldShow(level, lastRewardedAt)` (побочный эффект только у rewarded-скипа), `markShown()`.
- Владелец гейта — `_AppRootState` (живёт всю сессию).

## 2. Тема на сутки за rewarded

- На карточке некупленной темы два действия: тап по карточке — купить навсегда за осколки (как раньше), отдельная жёлтая кнопка `tv 24H` — примерить за ролик.
- После ролика: `trialUntil[ti] = now + 24h`, тема применяется как обычная; запоминается `preTrialTheme` (последняя честно купленная).
- Один trial-ролик **в день на все темы разом** (`trialAdDay`, сутки UTC — как остальные дневные лимиты).
- По истечении — откат на `preTrialTheme` (если она куплена, иначе тема 0) + тост. Проверка в `checkDay()` до раннего выхода (вызывается при resume, победах, действиях в хабе). `gameTheme` дополнительно защищён: истёкшая trial-тема не отрисовывается.
- Карточка активной trial-темы показывает остаток часов (`{h}h`); тап применяет тему без списания.
- Сейв (формат synapse_v1, обратная совместимость: ключи опциональны): `tru` — список меток истечения (ms), `trd` — день последнего trial-ролика, `trp` — тема отката. `resetProgress` всё обнуляет.
- Строки (`kStrings`, 9 языков): `thTrialGot`, `thTrialEnd`. Кнопка — иконка + «24H», без перевода.
