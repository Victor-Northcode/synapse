# SYNAPSE

Неоновая головоломка: распутывай провода повреждённой нейросети OM-9 и
возвращай ей память. Нативное Flutter-приложение — полный порт игры,
раньше жившей в одном `index.html`.

- 9 языков (en / ru / es / fr / de / it / ja / ko / ar, включая RTL)
- 9 механик-препятствий, мосты, зоны протечки, бомбы, бонусы
- главы с сюжетом, датацентр с задачами, цели дня, цели недели и стрик
- нижнее меню: Журнал · Склад · Топ · Настройки
- склад: бустеры, подсказки, мастерская (постоянные улучшения),
  8 тем с разными материалами кабеля; не хватает осколков —
  вместо цены кнопка «за ролик» (до 3 предметов в день)
- топ игроков работает ВСЕГДА: уровень оператора, личные рекорды и
  локальный рейтинг соперников — без сети; онлайн-таблицы
  подключаются, когда настроены
- реклама только добровольная, за награду (AdMob + UMP-согласие)
- лёгкая фоновая эмбиент-музыка (синтез, бесшовная петля) и звуки,
  которые НЕ прерывают музыку телефона (ambient + mixWithOthers)
- локальные напоминания: одно в день, в 19:00, на неделю вперёд,
  тексты не повторяются
- синтез звука на лету, тактильная отдача, офлайн-работа

## Сборка

```bash
flutter pub get
flutter build apk --release        # Android → build/app/outputs/flutter-apk/
flutter build ipa --release        # iOS: ТОЛЬКО на macOS с Xcode —
                                   #   Apple не позволяет собирать ipa на других ОС.
```

iOS-проект полностью подготовлен (портретная блокировка, ATT-описание,
тестовый GADApplicationIdentifier) — на Mac достаточно открыть проект,
выбрать команду подписи и выполнить `flutter build ipa`.

Без Mac под рукой IPA собирает workflow `.github/workflows/ios-ipa.yml`
(репозиторий Victor-Northcode/synapse): GitHub Actions
запускает облачный macOS-раннер, собирает `flutter build ios --no-codesign`
и выкладывает `SYNAPSE-unsigned.ipa` артефактом. Запуск — любым пушем в
main или кнопкой «Run workflow». IPA не подписан: для установки нужен
Sideloadly/AltStore (подпишут вашим Apple ID) или сертификат разработчика
в секретах репозитория — для TestFlight/App Store.

Проверки:

```bash
flutter analyze
flutter test                       # генератор, движок, смоук UI, адаптив
                                   # (320x568…800x1280, языки ru/de/ar/ja)
flutter test test/screenshots_test.dart --update-goldens   # скриншоты экранов
```

Весь интерфейс рисуется векторами: иконки из спрайта игры (flutter_svg),
осколок ✦, галочки, крестики и шестиугольники — CustomPaint. Эмодзи и
шрифтовые символы не используются нигде.

## Структура

```
lib/
  main.dart              точка входа: ориентация, системный UI, сервисы
  core/                  палитра, звук (WAV-синтез), хаптика, сохранения,
                         реклама (AdMob/UMP), локальные уведомления
  data/                  СГЕНЕРИРОВАННЫЕ данные из исходного index.html:
                         строки 9 языков, сюжет, задачи, иконки; + game_data
  game/                  чистая логика: геометрия, генератор уровней
  state/                 AppState (профиль, глава, магазин, цели)
                         PlayState (движок одного уровня)
  ui/
    app_root.dart        слои экранов и оверлеев, тосты, кнопка «назад»
    screens/             загрузка, хаб, склад, настройки, игра
    overlays/            результат, карточка механики, сюжет, политика
    widgets/             поле (CustomPainter), сцены, иконки, кнопки
```

Файлы в `lib/data/` (кроме `game_data.dart`) сгенерированы из исходного
HTML — править только через генератор, чтобы не разойтись с переводами.

## Сохранения

`shared_preferences`, ключ `synapse_v1`, структура JSON один в один с
веб-версией: `{l,t,s,sh,hs,dk,st,gp,gd,inv,ads,th,ow,ch,dn,hbq,so,vi,pu,i,lg}`.
Не менять — формат единый и документированный.

## Перед публикацией

1. **Реклама.** Сейчас стоят официальные ТЕСТОВЫЕ блоки Google.
   Заменить: `lib/core/ads.dart` → `_realUnit`, и app id в
   `android/app/src/main/AndroidManifest.xml`
   (`com.google.android.gms.ads.APPLICATION_ID`). Тестовые id в
   проде — нарушение политики AdMob.
2. **Подпись.** Release пока подписывается debug-ключом. Создать
   keystore и прописать в `android/app/build.gradle.kts`.
3. **iOS.** `NSUserTrackingUsageDescription` уже в Info.plist.

Правила продукта: реклама только за награду (никаких межуровневых и
баннеров), внутриигровых покупок нет — это осознанные решения владельца.

## Модерация: дети, приватность, анкеты консолей

Что уже сделано в коде (программа Google Play «Для всей семьи»,
COPPA, GDPR-K):

- **Нейтральный возрастной экран** при первом запуске (до любой
  рекламы): год рождения выбирается из списка, ничего не подставлено
  заранее, год хранится только на устройстве.
- **Ребёнок (до 13 лет)** → реклама в режиме `tagForChildDirectedTreatment`
  с рейтингом контента **G**; **до 16 лет** → `tagForUnderAgeOfConsent`,
  без персонализации и без формы согласия; **взрослые** → UMP-согласие
  (ЕЭЗ) и ATT (iOS). Пока год не указан, действует детский режим.
- Реклама только от **AdMob** — сеть сертифицирована для Families Ads
  Program; форматы — только rewarded по явному нажатию.
- В игре нет насилия, покупок, чатов, UGC; сюжет и графика подходят
  детям. Сетевой топ передаёт только случайный псевдоним и число —
  персональных данных нет ни у детей, ни у взрослых.
- Политика: `PRIVACY.md` (EN+RU, разделы про детей, GDPR, COPPA) и та
  же политика внутри игры (Настройки → Политика приватности).

Ответы для анкет (владелец заполняет в консолях):

**Google Play → Целевая аудитория:** можно выбирать группы с детьми —
требования Families выполнены (нейтральный экран + детский режим
рекламы + сертифицированная сеть). Отметить «в приложении есть
реклама».

**Google Play → Безопасность данных (Data safety):**
- «Собирает ли приложение данные?» — Да.
- Тип: *Идентификаторы устройства* — собирает партнёр (Google AdMob)
  для рекламы и защиты от мошенничества; передаются Google; сбор
  необязателен (реклама только по нажатию); шифруются при передаче;
  удаление — сбросом рекламного идентификатора в настройках системы.
- Больше никаких типов не собирается (игровой псевдоним случайный и
  анонимный, к перечисленным типам персональных данных не относится).

**Google Play → Рейтинг контента (IARC):** насилия нет, секса нет,
наркотиков нет, азартных игр нет, покупок нет, реклама есть,
пользовательского контента и общения нет → обычно 3+/Everyone.

**App Store:** возрастной рейтинг 4+; категорию **Kids НЕ включать**
(иначе сторонняя реклама запрещена — наш путь: обычная категория
Games/Puzzle + возрастной экран). App Privacy: «Data Used to Track
You» — Identifiers/Device ID (только взрослые, после согласия ATT);
«Data Not Linked to You» — Identifiers + Advertising Data. В заметке
для ревьюеров пояснить HTTP-исключение для dreamlo.com: передаётся
только анонимный игровой счёт со случайным псевдонимом, персональных
данных нет.

Дисклеймер: это инженерная подготовка, а не юридическая консультация;
финальную ответственность за анкеты несёт владелец аккаунтов.

## Таблицы лидеров

Топ-100 «распутано связей», вкладки «за неделю» и «за всё время».
iOS — Game Center (таблицы `synapse.links` классическая и
`synapse.links.week` повторяющаяся с недельным сбросом), Android —
Play Games Services (один лидерборд, недельный срез платформенный).
Вход в одно касание, очки уходят при каждой победе, экран топа — свой
(медали топ-3, своя строка закреплена), полная таблица — системная.

Чтобы включить:
1. **iOS**: App Store Connect → приложение → Game Center → создать обе
   таблицы с ID выше; developer.apple.com → Identifiers →
   `com.synapse.link` → включить capability Game Center.
2. **Android**: Play Console → Play Games Services → Setup: создать
   проект, лидерборд; Project ID → `android/.../values/strings.xml`,
   ID таблицы (CgkI…) → `lib/core/leaderboard.dart` (`androidBoard`).
Вкладка «Топ» работает всегда: уровень оператора и личные рекорды —
локальные; онлайн-часть появляется, когда таблицы настроены и есть сеть,
иначе экран честно объясняет, что общий рейтинг требует интернета.

## Экономика

Осколки ✦ — редкая «премиальная» валюта (в вебе была бы за деньги,
здесь — только за игру и ролики): цели дня (+1 каждая), цели недели
(+3/+3/+4), вехи серии (3/7/14 дней), каждая 10-я связь (+1), финал
главы (+5), мастерство на «очень сложных» связях, уровень оператора
(+2), ролик (+1, до 3 в день — ролик всегда ШАГ накопления, никогда не
готовая вещь). Стоки: бустеры (4–8✦), подсказки (6✦+), мастерская
(40–340✦, навсегда), темы (14–40✦). Избыток энергии: обмен 40⚡ → 1✦
(до 2 в день).

Сложность растёт кривой: бюджет ходов на связи #1 — с запасом ×1.08,
к #50 плавно ужимается до ×0.80 (сложные ×0.94, очень сложные ×0.88
сверху) — начало прощает всё, дальше решает навык.
